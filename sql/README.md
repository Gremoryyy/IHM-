# SQL / Base de données

La base de données n'est pas stockée en version "vivante" dans Git.

Le dépôt contient le script SQL permettant de recréer la base :

- Nom de la base : `robot6ddl`
- Fichier attendu : `robot6ddl.sql`

Import possible via :

- **phpMyAdmin** (import du fichier SQL)
- **MySQL CLI** (`mysql -u <user> -p < robot6ddl.sql`)
