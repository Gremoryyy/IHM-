# Workflow Git (règles simples)

## Règles

- Une branche par élève et/ou par fonctionnalité.
- Le développement se fait sur la branche dédiée.
- Le merge vers `main` se fait seulement quand le contenu est propre.

## Interdits

- Ne pas travailler directement sur `main`.
- `main` doit rester stable.
- Ne pas déposer des fichiers en vrac à la racine du dépôt.
